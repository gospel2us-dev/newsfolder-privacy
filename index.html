뉴스폴더(NewsFolder) 개인정보처리방침

시행일: 2026년 11월 1일 · 최종 수정일: 2026년 11월 1일

「뉴스폴더(NewsFolder, 일본어 ニュースフォルダ)」(이하 "앱")는 사용자가 고른 뉴스 기사에서 광고와 메뉴를 걷어내고 본문을 정리해 주는 개인 보관용 도구입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다. 핵심은 한 줄입니다: 개발자는 사용자의 정보를 수집하지 않으며, 기사는 사용자의 기기 안에서만 처리됩니다.

1. 수집하는 정보

없습니다. 앱에는 회원가입이나 로그인이 없고, 개발자의 서버도 없습니다. 기사 내용, 링크, 사진, 코멘트는 개발자에게 전송되지 않습니다.

예외 — 사용자가 직접 보내는 오류 신고: 정리 결과 아래의 「정리가 이상해요 · 신고」를 누르면 사용자의 메일 앱에 신고 메일 초안이 열립니다. 초안에는 기사 주소, 앱이 고른 제목, 앱 정보(버전, 정리 방식, 남은 문단·제거된 줄·사진 개수)만 들어 있고 기사 본문은 들어 있지 않습니다. 사용자가 내용을 확인하고 직접 보낼 때에만 개발자 이메일로 전달되며, 보내는 사람의 이메일 주소도 함께 전달됩니다. 받은 신고는 정리 오류를 고치는 데에만 쓰고, 수정이 끝나면 삭제합니다.

2. 앱이 기기 안에서 다루는 정보

정보사용 목적보관 위치
사용자가 붙여넣거나 공유한 기사 글, 링크, 사진기사 정리, 복사, 보내기기기 안에서만 처리하며 개발자에게 보내지 않음. 앱을 닫거나 새로고침하면 화면에서 지워짐
기기 이름, 자주 쓰는 받는 사람 이메일, 보내는 사람 이메일(사용자가 직접 입력한 경우)메일 보내기 때 다시 입력하지 않도록 기억앱의 기기 내 저장소에만 저장. 앱을 삭제하면 함께 삭제됨
클립보드사용자가 "붙여넣기" 버튼을 눌렀을 때만 읽어 기사로 가져옴읽은 내용은 기기 안에서만 처리
「내 폴더」에 저장한 기사(제목, 본문, 출처 주소, 사진, 한줄 코멘트, 분류)와 분류 선택 기록사용자가 저장한 기사를 분류별로 다시 보기, 비슷한 기사의 분류 추천앱의 기기 내 저장 공간에만 저장. 앱을 삭제하면 함께 삭제됨. 사용자가 「내보내기」를 누른 경우에만 사용자가 고른 곳(드라이브, 메일 등)으로 파일이 만들어짐
기사 사진 임시 파일메일·메신저로 보낼 때 사진 파일 첨부기기의 임시 저장 공간. 시스템이 정리함

3. 기사 페이지를 가져올 때

사용자가 기사 링크를 붙여넣거나 다른 앱에서 공유하면, 앱은 사용자의 기기에서 해당 언론사 사이트로 직접 접속해 페이지와 사진을 내려받습니다. 이 접속에는 일반적인 웹 접속과 같이 기기의 IP 주소 등이 해당 사이트에 전달될 수 있으며, 그 사이트의 개인정보처리방침이 적용됩니다. 개발자는 이 정보에 접근할 수 없습니다. 유료(구독) 기사는 구독하지 않은 사용자에게 제공되는 앞부분만 가져오며 우회하지 않습니다.

4. 제3자에게 제공

앱은 정보를 제3자에게 제공하지 않습니다. 다만 사용자가 "보내기"로 Gmail, 노트 앱, 메신저 등을 직접 선택하면, 선택한 앱에 내용이 전달되며 그 이후는 해당 앱의 방침을 따릅니다.

5. 광고와 분석 도구

현재 버전에는 광고와 사용 분석(통계) 도구가 없습니다. 이후 광고(예: Google AdMob)나 결제 기능을 추가하는 업데이트를 할 경우, 광고 식별자 등 수집되는 정보와 이용 목적을 이 방침에 먼저 반영하고 필요한 동의 절차를 제공하겠습니다.

6. 저작권 안내

뉴스 기사의 저작권은 각 언론사와 기자에게 있습니다. 앱은 개인 보관용 스크랩 도구이며, 기사 전문을 블로그, SNS, 단체방 등에 게시하는 것은 언론사의 이용 규칙에 따라 제한될 수 있습니다. 다른 사람과 나눌 때는 링크 공유를 권장합니다.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 수집하지 않습니다.

8. 이용자의 권리

앱이 기기에 저장한 정보(위 2항의 이메일 등)는 앱의 입력 칸에서 직접 지우거나 앱을 삭제해 모두 없앨 수 있습니다. 개발자는 사용자의 정보를 보관하지 않으므로 별도로 열람·삭제를 요청할 정보가 없습니다.

9. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경일과 함께 공개합니다.
